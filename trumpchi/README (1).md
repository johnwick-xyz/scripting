# 广汽传祺 App 签到（Loon）

每天 9:00–9:45 之间随机签到一次。传祺的签到接口没有公开文档，所以这个插件不写死接口，
而是先抓一次你手动签到时的真实请求，之后每天定时重放这个请求。

## 文件

- `Trumpchi.lpx` — Loon 插件：抓取凭证 + 每天 9:00–9:45 每 5 分钟触发一次，脚本随机挑一个时间签到
- `TrumpchiGetAuth.js` — 抓取脚本：存 Cookie / Token，并把签到请求（URL+方法+请求头+请求体）整个记下来
- `TrumpchiSign.js` — 定时签到脚本：重放抓到的签到请求，Cookie 会换成最新抓到的
- `README.md` — 本文件

## 安装

1. 把这 3 个文件（`Trumpchi.lpx`、`TrumpchiGetAuth.js`、`TrumpchiSign.js`）传到 GitHub `johnwick-xyz/scripting` 的新文件夹 `trumpchi/` 里。
2. Loon → 插件 → 右上角 + → 从 URL 添加，填：
   `https://raw.githubusercontent.com/johnwick-xyz/scripting/main/trumpchi/Trumpchi.lpx`
3. 确认插件已开启，Loon 保持开启。

## 抓一次签到请求（只做一次）

1. Loon 开着，打开广汽传祺 App。
2. 进「我的」→ 任务中心 → 每日签到，手动点一次签到（得 G 豆的那个）。
3. 等 Loon 通知：
   - 「传祺 Cookie 已抓取」/「传祺 Token 已抓取」——凭证存好了
   - 「传祺签到请求已记录」——签到请求存好了，明天 9:00–9:45 之间随机签
4. 如果只收到凭证通知、没有「签到请求已记录」，说明那次签到没走到带 sign / checkin 字样的接口：
   在 Loon → 请求记录里找刚才签到那一下的请求，把 URL 发我，我把匹配规则改一下。

## 每天怎么工作

- 每天 9:00–9:45，插件每 5 分钟触发一次 `TrumpchiSign.js`。脚本在当天第一次触发时随机抽一个目标时间（9:00 + 0~45 分钟），到了那个时间才真正签到，一天最多签一次。
- 签到成功 / 已签到会通知一声；失败了不立即通知，在 9:45 之前每个触发点都会自动重试，只有最后一个触发点（9:45）还失败才通知。
- 凭证过期了会自动用最新抓到的替换；如果 App 很久没打开、凭证失效了，通知会报失败，
  那时再打开 App 手动签到一次，凭证和请求都会重新抓一遍，第二天恢复自动签。

## 如果 App 打不开 / 抓不到

- 打开 App 时页面加载失败：传祺可能做了证书锁定（跟之前电信 App 一样），Loon 的 MITM 会被挡住。
  先把 Loon 关掉确认 App 本身能正常用；如果关了能用、开了打不开，就告诉我，我再看别的路。
- 打开 App 正常、但一直没有抓取通知：App 可能没走 `gacmotor.com` 这个域名。
  在 Loon → 请求记录里翻一下传祺 App 的请求，把域名发我，我把 MITM 和规则改过去。

## 隐私

- Cookie / Token / 签到请求只存在 Loon 本机的 `$persistentStore` 里，不上传、不进 GitHub。
- 传到 GitHub 的只有这 3 个脚本文件，里面没有任何账号信息。
