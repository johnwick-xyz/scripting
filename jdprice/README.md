# 京东价格监控 Scripting 小组件

监控一个京东商品的实时价和涨跌，不设目标价。

当前默认商品：西昊豆包椅L1，SKU `100244780555`
链接：https://item.jd.com/100244780555.html

## 数据来源

京东公开的价格接口，不用登录：

- `GET https://p.3.cn/prices/mgets?skuIds=J_<SKU>&type=1`
- 备用：`https://pm.3.cn/prices/mgets?skuIds=J_<SKU>&type=1`
- 返回 `[{"id":"J_100244780555","p":"449.00","m":"499.00"}]`，`p` 是当前价

**注意：这个接口在我的电脑和云浏览器上两次都连接被重置，没法在这边验证。** 小组件是在你手机上直接拉的，手机网络和这边不一样，所以必须在真机上试一次才算数。如果手机上也不通，小组件会显示上次缓存的价格，并提示拉取失败。

**2026-11-21 更新：p.3.cn 在手机 Safari 里也直接没反应。** 查了这个商品的页面，里面写着“登录查看价格”，没登录的请求价格是被遮住的（`jdPrice":"4??"`），所以光靠不登录的 p.3.cn 很可能拿不到价。改法：小组件现在支持京东 Cookie，取价时带 Cookie 去拉 p.3.cn / pm.3.cn，拉不到再带 Cookie 拉商品页，从页里的 `jdPrice` 取真价。Cookie 在 App 设置页手动填，或用 Loon 抓（`JdGetCookie.js` / `Jd.lpx`，抓 p.3.cn 和商品页的请求头，写 BoxJs key `jd_cookie` / `@JD.cookie`，只存含 `pin=` 或 `thor=` 的登录 Cookie）。Cookie 不要提交到 GitHub。

## 涨跌怎么算

每次 App 打开时把价格记进本地 `price_history.json`（最多 30 条），涨跌 = 当前价 - 上一次记录的价。最低 / 最高也是从这份本地历史里算的，不是京东官方的历史价。

**重要改版（2026-11-21）：小组件本身不联网，只读缓存。** 测试证明不联网的小组件能正常出来，卡住的是小组件里拉 p.3.cn / BoxJs 那几步网络——在小组件里 fetch 一旦没反应就一直转圈。所以取价只在 App 里做（`index.tsx`，打开 App 自动拉一次，也有“刷新价格”按钮），拉到价就存下来，小组件只读缓存，秒出。想看最新价就打开一次 App。**注意：App 和小组件是两次分开的执行，不能靠文件传数据**——2026-11-21 晚 App 已拉到 ¥479.00 但小组件读不到 `cache.json`，就是这个原因。官方文档的办法是全局 `Storage`，`shared: true` 才是跨界面共享的域，所以现在 App 写 `Storage.set('jd_price_cache', data, { shared: true })`，小组件先读 Storage，文件只当备用。

自动更新时间点可以在 App 里手动改（“刷新时间”一栏，填整点小时，用逗号隔开，例如 9,15,21；也可以写 9:00,15:00，分钟忽略），默认 9:00、15:00、21:00。两个京东小组件共用同一份设置，改一边两边都生效；填错、填空就回默认。打开 App 时按更新点这个规则自动拉；点“刷新价格”随时都能手动拉。

商品图：小组件价格右边显示京东主图（西昊豆包椅L1 主图 `https://img10.360buyimg.com/img/jfs/t1/572241/19/12897/149428/6afed993F3dda89e5/008332032016639f.jpg`，已验证能打开）。App 拉价时会顺带从商品页取第一张主图存进缓存，换商品自动换图；App 设置里也可以手动贴图片链接。底部一行：最低 / 最高 / 更新时间必须写成一整行 Text 加 minScaleFactor，拆成三个 Text 放 HStack 会被截成“4…”这种半截。

iOS 决定刷新频率，一般 15-30 分钟一次，不是秒级实时。

## 文件

- `script.json`：Scripting 项目清单
- `widget.tsx`：小组件本体，四个尺寸：小号 / 中号 / 大号（带最近走势条形图）/ 锁屏（圆形只显示价格，矩形显示简称 + 价格 + 涨跌）
- `index.tsx`：App 内设置页，改商品编号和简称就能换商品，不用改代码；也可以清空价格历史
- `utils.tsx`：`rpt` 换算
