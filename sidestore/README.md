# 证书倒计时（手动版，二合一马蹄圈）

SideStore / LiveContainer 证书到期倒计时，手动填到期日。

## 为什么是手动的

自动读真实到期时间要靠 RPP 配对 + Scripting 的 VPN API 建 RSD 隧道去读描述文件。但 VPN API（`VPN.localDevVPN.openRSDTunnel`）只有 Scripting TestFlight 3.2.2 版才有，App Store 最新版里没有，内测名额也拿不到（2026-11-24 实测）。所以先用手动记的。

以后要是拿到了 TestFlight 3.2.2，可以换 `RefreshSideStore` 那个版本自动读，配对记录已经做完了，不用重新配对。

## 显示

- **小号**：一个马蹄圈，显示 SideStore / LiveContainer 里先到期的那个。
- **中号**：两个都填了就并排显示两个马蹄圈（左 SideStore、右 LiveContainer，各有自己的天数和到期日）；只填了一个时退回单圈 + 右侧列表。
- **大号**：第一个应用大圈 + 其余应用列表。
- **锁屏圆形**：第一个应用的剩余天数；**锁屏矩形**：名字 + 剩余。
- 圈的颜色按剩余比例变：绿 → 黄绿 → 黄 → 橙 → 红；不到 1 天或已过期变红。
- 每小时刷新一次，天数跟着变。

## 怎么用

1. 在 Scripting 里导入这个文件夹（或直接把文件放进项目）。
2. 打开 App：SideStore 和 LiveContainer 各有一栏。
   - 点「刚续期」：到期时间从现在起往后数 7 天（免费证书）或 365 天（付费证书），按上面选的有效期。
   - 也可以直接用日期选择器，把 SideStore「我的应用」里显示的到期日填进来（点开应用就能看到；或者去设置 → 通用 → VPN 与设备管理 → 描述文件里看到期日）。
3. 在 SideStore 里点一次刷新续期后，记得回来点一下对应应用的「刚续期」，不然倒计时不会自己变。
4. 还能点「添加应用」再加别的侧载 App（比如 StikDebug），单独倒计时。

## 防忘、防填错

- **到期提醒**：填好到期日后，App 会自动排一条本地通知，在到期前 1 天提醒你续期（点通知就回到这个页面）。设置页的「到期提醒」一栏会显示有没有排上；如果显示没排上，去 iOS 设置 → Scripting → 通知里允许通知，再回来改一下日期。
- **填错提示**：日期已经过了、或者超出证书最长有效期（免费 7 天、付费 365 天），设置页会红字标出来，提醒你检查。
- **不用打字**：续期后点「刚续期」就行，到期时间自动从现在起往后数，不用自己输日期。

## 数据

存在 Storage 共享域 `ss_cert`（App 和小组件共用），同时写一份 `cache.json` 备用：

```json
{ "validityDays": 7, "apps": [{ "id": "sidestore", "name": "SideStore", "expiryTs": 1730000000000 }], "updatedAt": 1730000000000 }
```

只有你填的到期日，没有任何账号、Cookie 或证书内容，不会上传。

## 文件

- `script.json`：项目信息（名字「证书倒计时」，图标 timer）。
- `widget.tsx`：小组件入口，读缓存、每小时刷新。
- `index.tsx`：设置页（到期日、刚续期、添加/删除应用）。
- `view.tsx`：马蹄圈 + 二合一布局。
- `model.ts`：倒计时计算、二合一匹配、日期格式。
- `appearance.ts`：卡片背景渐变。
